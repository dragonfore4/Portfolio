Homelab · architecture · 2026-10-19

One box, two lanes, two floating IPs.

Web traffic enters at 192.168.1.200 and is carried by MetalLB and Traefik into Kubernetes. Database traffic enters at 192.168.1.150 and is carried by keepalived and HAProxy to the Patroni leader. Kubernetes apps that need a database use the same floating IP, .150. Each address floats between VMs, but all of them run on one GMKtec host.
